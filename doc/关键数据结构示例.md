## 2. 核心实体定义

### 2.1 语言与词汇

#### Language（语言）
| 字段 | 类型 | 说明 |

| Code | string | 主键，如 zh / de / en |
| Name | string | 英文名 |
| NativeName | string | 本地名称 |
| IsSource | bool | 是否可作为母语 |
| IsTarget | bool | 是否可作为目标语 |
| Metadata | Dictionary | 扩展信息（是否有性别、书写方向等） |
| IsActive | bool | 是否启用 |

#### Concept（语义概念）
| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| ConceptKey | string | 可选标识（house / go） |
| Description | string | 备注 |

#### Lexeme（词条）
| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| ConceptId | Guid? | 关联语义概念 |
| LanguageCode | string | 语言 |
| BaseForm | string | 原形（德语推荐写「das Haus」） |
| PartOfSpeech | string | Noun / Verb / Adj... |
| Features | Dictionary | 性别、是否可分动词等 |
| ExampleSentence | string | 例句 |
| AudioUrl | string | 主音频 |
| Frequency | int | 词频 |
| IsActive | bool | 是否启用 |

#### MorphForm（形态变化）
| 字段 | 类型 | 说明 |
|------|------|------|
| Id | long | 主键 |
| LexemeId | Guid | 所属词条 |
| Form | string | 具体形态 |
| Tags | Dictionary | Case / Number / Person / Tense 等 |
| AudioUrl | string | 该形态音频 |
| SortOrder | int | 展示顺序 |
| IsCommon | bool | 是否常用形态 |
| Note | string | 备注 |

### 2.2 短文（扁平化设计）

#### Passage（短文）
| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| Title | string | 标题 |
| TargetLanguage | string | 目标语言 |
| SourceLanguage | string | 母语（可选） |
| Difficulty | int | 难度 1-5 |
| ContentType | string | Reading / Listening / FollowRead / Story / Dialog |
| FullText | string | 完整纯文本（搜索与展示） |
| AudioIntervalMs | int | 句子间播放间隔（毫秒），默认 800 |
| SceneMediaUrl | string | 场景图/动图 |
| Sentences | List\<PassageSentence\> | **有序句子列表（直接内嵌）** |
| Metadata | Dictionary | 扩展信息 |
| IsActive | bool | 是否启用 |
| PublishedAt | DateTime? | 发布时间 |

> **已移除整篇 AudioUrl**。播放时由前端按句子音频顺序 + 间隔拼接实现。

#### PassageSentence（短文中的一句）
| 字段 | 类型 | 说明 |
|------|------|------|
| Order | int | 顺序（从 0 开始） |
| Text | string | 该句文本 |
| AudioUrl | string | **该句独立音频（必须）** |
| DurationMs | int? | 音频时长（可选，用于进度） |
| Tokens | List\<PassageToken\> | 该句分词列表 |

#### PassageToken（句子中的词/标点）
| 字段 | 类型 | 说明 |
|------|------|------|
| Position | int | 在句子中的位置 |
| SurfaceForm | string | 实际显示形式 |
| MorphFormId | long? | 精确关联形态（推荐） |
| LexemeId | Guid? | 关联原形（备用） |
| IsPunctuation | bool | 是否标点 |
| IsClickable | bool | 是否可点击提示 |
| HintOverride | Dictionary | 特殊提示覆盖 |

**点击提示逻辑**：优先用 `MorphFormId` 获取形态+音频+标签，再用 `LexemeId` 获取原形与翻译。

#### Question（统一题目）
| 字段 | 类型 | 说明 |
|------|------|------|
| Id | Guid | 主键 |
| Type | string | ChoiceFill / FillBlank / MultipleChoice / BuildSentence / Matching / FollowRead / ListeningComprehension |

- 填空：`{"display":"Das ist mein ____.","answer":"Haus","morph_form_id":123}`

## 3. 关键能力实现方式

| 需求 | 实现方式 |
|------|----------|
| 德语名词带 der/die/das | Lexeme.BaseForm 直接写完整形式 + Features.Gender + MorphForm |
| 句中单词可点击提示 | PassageToken 关联 MorphFormId / LexemeId |
| 短文跟读 / 连续播放 | 前端按 Sentences 顺序播放 AudioUrl，中间插入 AudioIntervalMs |
| 短文挖空出填空/选择题 | 遍历 Tokens，动态或预生成 Question |
| 多角色情绪语音 | Character.VoiceProfiles + DialogueTurn.Emotion |
| 免注册试用 | User.IsGuest = true |
| 邀请奖励 | InvitationCode + InvitationReward |
| 论坛强制语言 | ForumPost.AllowedLanguage + 后端校验 |
| 题型无限扩展 | Question.Type + Config（JSONB） |

---

## 4. 设计决策说明

1. **Passage 去掉整篇音频**：降低制作成本，提升更新灵活性，跟读间隔天然支持。
2. **短文采用内嵌句子+分词**：结构扁平，避免三层实体带来的冗余。
3. **MorphForm 保持独立表**：精确支持变格变位查询与音频绑定。
4. **大量使用 Dictionary**：对应 PostgreSQL JSONB，保证未来扩展无需改表。
